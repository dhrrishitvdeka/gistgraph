# M0: scaffolding

This milestone adds no model code. It sets up the things every later milestone relies on.

## Package layout

`src/gistgraph/` uses a *src layout*: the package is only importable once installed
(`pip install -e .`), so tests always exercise the installed package, not the working directory.

## Config system (`gistgraph/config.py`)

Experiments are YAML files parsed into nested dataclasses (`Config` at the root).

- **Why dataclasses, not a plain dict:** typos fail loudly. A key that does not exist in the schema
  raises `KeyError`, and a value of the wrong type raises `TypeError`. A silently ignored typo in a
  research config is a classic source of wrong results.
- **`base:` inheritance:** a config can list parent files. They are deep-merged in order, and
  later ones win. Experiment files only need to state what differs from `configs/base.yaml`.
- **Overrides:** `train.lr=1e-4` style strings patch single values. The value is parsed as YAML,
  so `false` is a bool and `5` is an int. PyYAML reads `1e-4` as a string (YAML 1.1 wants a dot),
  so float fields convert such strings.
- **Resolved config on disk:** `save_config` writes the full config next to each run's outputs.
  Together with the seed this is what makes a run reproducible.

## Seeding (`gistgraph/utils/seed.py`)

`seed_everything` seeds Python, NumPy and PyTorch (if installed) and can request deterministic
cuDNN kernels. PyTorch is imported lazily so the early milestones need no GPU stack.

## Tooling

- **CI** (`.github/workflows/ci.yml`) runs `ruff check`, `ruff format --check` and `pytest`.
- **Local lint caveat:** on the development machine an Application Control policy blocks native
  executables in virtual environments, so `ruff` cannot run locally. Locally the code is checked
  with `pyflakes`, `pycodestyle --max-line-length=100` and `black --check -l 100` as stand-ins, and
  CI is the authority for ruff. Install ruff directly on any machine where it is allowed.

## Reproduce

```bash
pip install -e ".[dev]" && pytest
```
