# M0: scaffolding

This milestone adds no model code. It sets up the things every later milestone relies on.

## Package layout

`src/gistgraph/` uses a *src layout*: the package is only importable once installed
(`pip install -e .`), so tests always exercise the installed package, not the working directory.

## Config system (`gistgraph/config.py`)

Experiments are YAML files parsed into nested dataclasses (`Config` at the root).

- **Why dataclasses, not a plain dict:** typos fail loudly. A key that does not exist in the schema
  raises `KeyError`, and a value of the wrong type raises `TypeError`. A silently ignored typo in a
  research config is a classic source of wrong results.
- **`base:` inheritance:** a config can list parent files. They are deep-merged in order, and
  later ones win. Experiment files only need to state what differs from `configs/base.yaml`.
- **Overrides:** `train.lr=1e-4` style strings patch single values. The value is parsed as YAML,
  so `false` is a bool and `5` is an int. PyYAML reads `1e-4` as a string (YAML 1.1 wants a dot),
  so float fields convert such strings.
- **Resolved config on disk:** `save_config` writes the full config next to each run's outputs.
  Together with the seed this is what makes a run reproducible.

## Seeding (`gistgraph/utils/seed.py`)

`seed_everything` seeds Python, NumPy and PyTorch and can request deterministic cuDNN kernels
(`deterministic=True`, off for long training runs because it can be slower). Data order and the
per-batch compression ratio are derived from the seed and the step, so a resumed run continues
exactly where it stopped.

## Tooling

- **CI** (`.github/workflows/ci.yml`) runs `ruff check`, `ruff format --check` and `pytest` on
  Python 3.10 and 3.11, with the CPU build of PyTorch.
- **Lint status, stated plainly:** the original development machine could not run the `ruff`
  executable (a system policy blocked it). The code was checked locally with `pyflakes`,
  `pycodestyle --max-line-length=100` and `black --check -l 100` as stand-ins, which agree with
  ruff on almost everything but not every rule. The workflow had not run on GitHub when this note
  was written, so the first CI run may report ruff findings that need a small follow-up fix.
- **Pre-commit** (`.pre-commit-config.yaml`) runs ruff and ruff-format.

## Repository hygiene

- Apache-2.0 `LICENSE` and a `NOTICE` naming the copyright holder.
- `CITATION.cff` (so GitHub offers a "Cite this repository" button), `CONTRIBUTING.md`,
  `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CHANGELOG.md`, issue and pull-request templates.
- `.gitattributes` pins text files to LF line endings. Text files are UTF-8 without a byte-order
  mark, because strict YAML and CFF parsers can reject one.
- `.gitignore` anchors artifact directories to the repo root (`/runs/`, `/cache/`, `/data/`) so
  they do not also hide source packages such as `src/gistgraph/data/`.

## Reproduce

```bash
pip install -e ".[dev]" && pytest
```
